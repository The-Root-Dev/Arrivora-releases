# Arrivora

Arrivora vous aide à organiser vos tournées de livraison en trouvant un ordre de trajet plus efficace pour vos différentes destinations.

Comment utiliser Arrivora ?

1. Ajouter votre point de départ

Pour définir votre position de départ :

1. Ouvrez Google Maps.
2. Appuyez sur le point bleu qui indique votre position actuelle.
3. Sélectionnez "Partager cette localisation".
4. Copiez le lien obtenu.
5. Collez-le dans le champ Départ dans Arrivora.

---

2. Ajouter les destinations des clients

Si un client vous envoie sa position

Si votre client vous partage sa localisation par WhatsApp ou une autre application :

1. Copiez simplement le lien Google Maps reçu.
2. Collez-le dans le champ Localisation client correspondant.

Répétez cette étape pour chaque client.

---

Si vous devez ajouter l'adresse vous-même

Si vous ne possédez pas encore le lien de localisation :

1. Ouvrez Google Maps.
2. Recherchez l'adresse du client ou sélectionnez directement le lieu sur la carte.
3. Appuyez sur "Itinéraire" ou "Directions".
4. Appuyez sur "Partager" puis copiez le lien.
5. Revenez dans Arrivora et collez le lien dans l'espace Localisation client.

Vous pouvez actuellement ajouter jusqu'à 5 destinations clients.

---

3. Optimiser votre tournée

Une fois votre départ et vos destinations ajoutés :

1. Appuyez sur le bouton Optimiser.
2. Patientez quelques secondes pendant le calcul.
3. Le résultat apparaît avec l'ordre conseillé pour vos arrêts.

---

4. Démarrer votre trajet

Après l'optimisation :

1. Appuyez sur "Ouvrir dans Google Maps".
2. Vous verrez la carte complète avec tous vos points d'arrêt dans l'ordre recommandé.
3. Appuyez sur "Démarrer" dans Google Maps pour lancer votre navigation guidée.

Avec Arrivora, organisez vos livraisons plus simplement et gagnez du temps sur vos trajets.
