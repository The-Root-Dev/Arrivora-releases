# Arrivora

Optimisez vos livraisons, gagnez du temps.

Arrivora est une application d'optimisation de tournées de livraison conçue pour aider les livreurs et les professionnels à organiser leurs déplacements de manière plus efficace.

L'application permet d'ajouter plusieurs destinations, de calculer un ordre de trajet optimisé et d'ouvrir l'itinéraire final directement dans Google Maps.

---

# Présentation

Lorsqu'un livreur doit effectuer plusieurs livraisons, choisir le bon ordre des destinations peut faire perdre beaucoup de temps et augmenter les déplacements inutiles.

Arrivora simplifie ce processus en proposant un ordre de visite plus efficace pour vos différents points de livraison.

---

# Fonctionnalités actuelles

- Ajout d'un point de départ depuis Google Maps
- Ajout de plusieurs destinations clients
- Optimisation automatique de l'ordre des arrêts
- Génération d'un itinéraire complet dans Google Maps
- Navigation guidée avec Google Maps
- Interface simple et intuitive

---

# Comment utiliser Arrivora ?

1. Ajouter votre départ

1. Ouvrez Google Maps.
2. Appuyez sur le point bleu représentant votre position actuelle.
3. Sélectionnez Partager cette localisation.
4. Copiez le lien.
5. Collez-le dans le champ Départ dans Arrivora.

---

2. Ajouter les destinations clients

Si un client vous envoie sa position :

1. Copiez le lien Google Maps reçu.
2. Collez-le dans le champ Localisation client.

Si vous devez rechercher vous-même une adresse :

1. Ouvrez Google Maps.
2. Recherchez l'adresse.
3. Cliquez sur Itinéraire.
4. Partagez le lien.
5. Copiez-le dans Arrivora.

Actuellement, Arrivora supporte jusqu'à 5 destinations clients par optimisation.

---

3. Optimiser votre tournée

Après avoir ajouté votre départ et vos destinations :

1. Cliquez sur Optimiser.
2. Attendez quelques secondes.
3. Consultez l'ordre conseillé des arrêts.
4. Cliquez sur Ouvrir dans Google Maps.
5. Appuyez sur Démarrer dans Google Maps pour lancer la navigation.
